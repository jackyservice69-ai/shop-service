# Iya wallet surface v7

Edited with the built-in Imagegen tool at the owner's request on 26 October 2026. The existing v5 pink botanical wallet background was the edit target; the owner's screenshot was a bounds reference only. The result is full-bleed decorative artwork with no baked-in perimeter rim, text, logo, chip, balance, account information or QR.

The 1100×666 WebP is resized/encoded with Sharp from the selected generated PNG, retained locally under `output/imagegen/wallet-v7/`. Exact prompts and runtime use are documented in `docs/WALLET-CARD-V7-PROMPT.json` and `docs/WALLET-CARD-V7.md`. The earlier background and coin assets remain available for history.
