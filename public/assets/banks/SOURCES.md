# Receiving-bank symbols

Retrieved 2026-10-25. These files identify receiving banks; trademarks belong to their respective banks. No affiliation or endorsement is implied. Bank names are rendered as separate page text, not baked into these icons. Letter-based bank marks remain part of the bank's own symbol.

- The SVG symbol collection and background colours are from [Omise banks-logo](https://github.com/omise/banks-logo), pinned to commit `2d813bc9193fd3ebd8e2c94d7f60a8a25ba956b2`. Assets are unchanged; include `LICENSE.omise.txt` with them. The old TMB/KK symbols are not used for current TTB/KKP accounts.
- `ttb.svg`: [TTB official favicon](https://www.ttbbank.com/favicon.svg), retained unchanged. Used for EasySlip code `011` and the collection's `076` alias.
- `kkp.png`: [Thai Banks Logo KKP symbol](https://raw.githubusercontent.com/casperstack/thai-banks-logo/master/icons/KKP.png), retained unchanged. Used for `069`.
- `boc.svg`: [Bank of China symbol artwork](https://companieslogo.com/img/orig/601988.SS-1ff844da.svg?t=1720244490), retained unchanged. Cross-check identity against [Bank of China's own logo explanation](https://www.bankofchina.com/english/thisisboc/ab3/brd/202601/t20260104_25638404.html). Used for `052`.
- `clicx.ico`: [CLICX official favicon](https://clicxbank.com/favicon.ico), retained unchanged. Used for `088`.

`shared/bank-logos.json` maps 34 bank codes to 33 local assets. Bank-code alignment uses the [EasySlip bank-code reference](https://document.easyslip.com/th/reference/bank-codes), including the current TTB code and CLICX. This visual catalogue does not add receiving accounts or change which banks EasySlip accepts for a Branch.
